原件、页面提取、截图和协议全文均保存在 Git 忽略目录；本文仅记录来源、证据定位与结论。本地核查记录：

- `raw-data/cninfo-reports/`、`raw-data/currency-evidence/`、`raw-data/futu-rights/`：原始与中间证据。

两份 PDF 与两份官方 HTML 的原件 hash 均已本地重算核对。来源文件日期不等于精确发布时间，也不等于系统已知时间；实际获取时间见各原件元数据，不回填历史 `known_at`。新增比亚迪原件仅用于币种证据，未导入财务事实。

币种证据通过不自动批准 API 数据保存或来源政策。富途历史 `close` 仍仅有“收盘价”定义，本次没有新增 CAS FINAL、供应商纠错完结或正式 seal 证据；仍按 [接入准备说明](futu-readonly-setup.md) 的 REFERENCE 边界处理。不新增证券、模型外传、真实告警或交易。实际实现与数据库操作由主会话另行按已授权范围执行。
