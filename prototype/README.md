# 价值研究交互原型

直接打开[index.html](./index.html)。本地HTML/CSS/JavaScript，不需要安装依赖或启动产品服务；没有外部字体、图片、CDN、fetch/API请求。全部资料为两家合成公司、三只证券的固定交互样例。页面操作仅在内存中，刷新或“重置演示”清空。

路径：今日变化→当时解释→当前公司→原文→人工覆盖；公司评分/财务/A-H估值/笔记；三层模板→差异预览；策略候选→修改阈值→固定样例模拟→发布；管理模式的合成源→失败项恢复、质量更正、主体关系、用户角色、模型/费用与审计。

顶部“查看身份”切换五角色或研究员+策略管理员组合，仅为交互演示，不是真实认证。底部“设计状态演示”提供加载、空、部分失败、不可见、冲突、UNKNOWN/等待、新版本、停牌。改变策略阈值或模板设置会使旧预览失效。

所有评分/模拟输出为预先编写的对照材料，没有前端策略计算；不以原型保存/发布提示声称数据库写入。原型详解与需求连接见[16](../docs/16-prototype-and-design-trace.md)。产品实施与目标用户任务验收尚未执行。
