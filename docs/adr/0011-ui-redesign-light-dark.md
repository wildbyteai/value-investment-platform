# ADR 0011：界面重做（白天 / 黑夜模式）

- 状态：已采纳（2026-10-07，用户确认效果图）
- 范围：只改视觉与布局，不改功能、接口和数据。

## 决定

1. 一套设计令牌（`frontend/src/style.css` 顶部 CSS 变量），两种主题：
   - 白天模式（默认）：浅色、圆角卡片、靛蓝强调色。
   - 黑夜模式：深色投研终端风，数字用等宽字体，琥珀色强调。
   - 顶栏右侧按钮手动切换，选择记在浏览器 `localStorage["vip-theme"]`。
2. A 股习惯：利好/上涨红色，利空/下跌绿色（影响分、利好利空计数、检查项）。
3. 外框：左侧整高导航（品牌、五个菜单、未读告警数、身份切换收进底部），顶栏放当前菜单名、分页签、刷新与主题切换。
   - **2026-10-09 更新（视觉）**：设计令牌改为基于 Ant Design 设计规范（白天主色 #1677FF、黑夜 #1668DC，系统字体栈，5 级字号），黑夜模式不再用琥珀色与等宽数字；规范与令牌表见 docs/23 §6。
   - **2026-10-09 更新（布局）**：取消顶栏分页签，改为左侧两级导航（菜单 → 页面），顶栏只留“菜单 › 页面”标题、刷新与主题切换；见 ADR 0014 第 8 条、docs/23 §2.1。
4. 资讯雷达：指标条 + 事件列表（关联公司、最高关联度、影响分、状态）+ 右侧事件详情（关联公司卡片内确认/驳回、合并来源）。
5. 击球区：指标条 + 「安全边际 × 经营分」散点图（甜区/边角球按配置门槛着色）+ 可按区域筛选的证券表。

## 验证

- `npm run build`（tsc + esbuild）通过，CI `frontend-build` 校验 bundle 与源码一致。
- 沙箱无浏览器，用 jsdom 跑真实 bundle + 模拟接口数据生成页面快照做布局核对；真实浏览器视觉验收需用户本机确认。
