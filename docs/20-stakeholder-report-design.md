# 20 面向需求方的图文报告方案

2026-10-07，报告版本0.6。成果：PDF审阅版（本机成品，不入Git）、可编辑Word（本机成品，不入Git）、[制作检查记录](../review/stakeholder-report-build-evidence.json)。产品设计基线仍为v0.3；报告版本不代表产品版本或上线状态。

## 2. 案例与图表

“远景制造 / SYN-A、SYN-H”是合成业务推演，不是真实公司评级或产品验收。假定股份同权、输入有效、适用非金融行业和合法应评估时点，固定演示汇率。D0–D6使用合成相邻应评估日，D7为独立风险知悉时点；衰减另按明确的自然日年龄说明。

案例贯穿：10亿元普通股盈利和10亿同权股→EPS1元；A价20元与H价16港元、汇率0.90→PE20与14.4、估值分33.33与70.67；20亿元订单与上年100亿元收入→值得研究，不直接换算分数；演示成长贡献4、权重10%→总分79.0至79.4。财报吸收后不重复叠加。

缺行情不复用旧价，保留最后确认状态并重置计数，恢复后从1/2重新开始。D5估值分54.47满足保持门。D7采用现有confirmed_debt_default，不发明资产负债率一票否决。税费、南向交易资格及通道日历未纳入现有模型，按影响回报和可执行性的扩展事项说明。

| 图ID | 内容与用途 |
|---|---|
| B-01 | 五步交接产物：资料、判断、评价、跟踪和复核 |
| B-02 | PE数轴上的A/H差异、进入门和保持门 |
| B-03 | 20亿元订单：五份出处、一个事实、贡献吸收 |
| B-04 | 八时点状态序列及缺数打断确认 |
| B-05 | 公司、原文判断和快照比较的信息结构，合成数值，非运行截图 |
| B-06 | 授权成员、域名、应用、研究数据与恢复职责，目标方案 |

采用A4纵向，正文约11.5pt，表格约10.5pt、图注约9.5pt。标题连续排版，不按章强制换页；表头重复、单行不跨页，图片与图注关联。实际截图已只读采集，记录版本、时间、角色、场景和隐私检查；原始业务像素仅留受限本机目录。

## 5. v0.5 管理层阅读与用词修订

成品保持12页，数值与八时点状态不改变。管理层摘要强调证据链与研究档案的组织资产价值；第2节前置沙盘设定卡，第6节以研究员、策略负责人、数据与系统运营三条工作流替代页面逐项罗列。岗位与实际capability区分，策略维护权不隐含修改判断权。

技术附件突出通用框架、自主管理及私有部署目标，说明软件许可、数据用途和外部合同的约束。预算基准仍沿用2026-10-06公开核查，不冒称10月7日重新询价。容灾采用一致性基线、WAL归档、异机保存与恢复演练；热备按可用性和成本选，不把热备写成达标的唯一方式。

| 修订项 | 报告采用口径 |
|---|---|
| 定位与沙盘 | 开篇管理层摘要；合成沙盘说明算法与状态，报告复算与产品验收分开 |
| A/H投资视角 | 不同币种与账户约束下的估值窗口；PE门不等于已经证明内在价值 |
| 事件因子 | 10为尺度、±15为单维度总截断；0.8为沙盘影响置信判断，非履约概率或自动折扣 |
| 去重和证据 | 当前批准的最强可访问证据确定来源质量，新证据可更新，转载不累加 |
| 状态机制 | Two-Day Confirmation、Interruption Reset、Hard Risk Override沿现有合同解释，避免绝对消除噪声的承诺 |
| 历史能力 | 历史快照回看和固定输入规则模拟；任意历史反事实的完整演练仍待扩展验收 |
| 自主与验收 | 降低平台绑定、可按目标私有部署；不承诺100%自主、零技术负债或已完成生产保障 |
| 排版 | 范围连接符用ASCII短横线；图注keep_with_next；紧凑质量/角色/八日表保持整体，长框架表允许重复表头续页 |
