# 真实资料参考计算（用户授权的增量行为）

本次目标：已有真实资料可形成参考PE、估值分、已覆盖维度加权分和逐条件策略比较。正式总分、FINAL价、有效股本、发布政策、封存与入选门槛不变。参考结果不推进策略状态，不自动接受经营建议。

## 范围与验收

- REF-01：仅复用现有权限及时点筛选后的输入；参考价可用于参考估值，A/H各用自己的币种、价格与同日汇率。
- REF-02：历史股本必须标明结存日、覆盖期限及“股数未变”的假设；已知期后变动另列警示。缺同权依据、币种不符、无同日汇率、非正TTM利润、失效财务均不生成PE。不以负PE给亏损企业高估值分。
- REF-03：参考经营分仅是已有效维度按已发布模板权重重新归一的分数，必须同时展示覆盖度及未覆盖维度；pending建议不计分。
- REF-04：按本工作区实际已发布策略逐条件比较。缺证据或覆盖不足时总结果为“部分可评估”；可见条件通过不等于入选。无已发布策略只展示计算，不假称正式规则比较。
- REF-05：公司页和新研究快照均展示参考结果、时点、依据和缺口；旧快照内容与幂等重放保持不变，撤权及跨工作区边界沿用原实现。
- REF-06：新增参考服务独立于正式封存计算；不修改原评分、策略状态机或FINAL标记，无迁移、无新增采集、无外发。

## 接口与追溯

公司score响应增加 `reference_quality`，证券增加 `reference_valuation` / `reference_strategy`。新研究快照采用 `local-research-preview-v3`，固定参考算法源码hash、原评分算法hash、规则hash及既有输入/判断引用。数值采用既有Decimal50位运算、12位HALF_EVEN量化。

`reference_strategy.result` 为 PARTIAL / MATCH / NO_MATCH / RISK_EXCLUDED / NOT_APPLICABLE / SUSPENDED / NO_RELEASE；全部 `applied=false`。逐条件提供actual/expected/op/result与basis。覆盖门槛失败属于依据不足，不解释成公司经营差。

验证：独立数值/失败边界测试，研究重放及撤权/工作区测试，正式封存回归，UI构建，以及本机真实库备份后追加一次研究并回读真实页面。具体执行结果见本轮证据文件（完成时更新）。
